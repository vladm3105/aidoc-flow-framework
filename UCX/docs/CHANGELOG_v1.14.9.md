# UCX v1.14.9 Changelog

**Release Date**: 2026-03-14

## Summary

Added automatic duplicate element ID fixer (GATE-E008) and improved reference context detection to eliminate false positive duplicate errors.

## New Features

### Duplicate Element ID Auto-Fixer

New `DuplicateElementFixer` class automatically renumbers duplicate element IDs across BRD documents:

```bash
# Standalone script
python scripts/fix_duplicate_ids.py docs/01_BRD/BRD-XX --dry-run
python scripts/fix_duplicate_ids.py docs/01_BRD/BRD-XX

# Integration with ucx validate --fix
ucx validate brd docs/01_BRD/BRD-XX --fix
```

**Algorithm**:
1. Scan all markdown files in BRD directory
2. Identify element ID definitions (not references)
3. Track first occurrence of each ID
4. Renumber duplicates with next available sequence number
5. Update all references to renamed IDs across files

**Files Added**:
- `ucx/validators/brd/duplicate_fixer.py` - Core module
- `scripts/fix_duplicate_ids.py` - CLI script

### Improved Reference Context Detection

Extended reference pattern recognition to eliminate false positive GATE-E008 errors:

| Pattern | Example |
|---------|---------|
| Category reference lists | `- Compliance BRDs: BRD.03.01.01 (Audit...)` |
| Multiple IDs on same line | `BRD.03.01.01, BRD.03.01.07, BRD.03.01.09` |
| Range notation | `BRD.03.32.01-11` |
| Parenthetical references | `(BRD.03.01.01)` |
| Business constraints | `- BRD.03.01.01: Description` |
| Review report files | `*_review_report*.md` |

**Excluded Directories**:
- `.ucx_review_session/`
- `.doc_review_memory/`
- `.backup/`
