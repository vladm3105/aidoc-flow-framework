## Problem Statement

Large documents (150K+ chars) split into 15-20 section files get merged by context engineering into prompts of 40-50K tokens. This creates challenges:

```
Large Document (150K+ chars)
    ↓
Split into 15-20 section files
    ↓
Context Engineering merges/filters
    ↓
Final prompt is 40-50K tokens
    ↓
??? What did the LLM actually receive ???
    ↓
Wait 2-3 minutes for LLM response
    ↓
Bad output → Wrong prompt → Repeat
```

| Issue | Impact |
|-------|--------|
| Can't manually review 50K token prompts | Errors go undetected until LLM responds |
| Section inclusion is opaque | Don't know what persona sees |
| Token budget unclear | Truncation, budget overruns |
| Slow feedback loop | Waste time waiting for bad output |

---

## Solution: Focused Inspection Tools

```bash
ucx prompts generate   # Dump prompts to files with metadata
ucx prompts inspect    # Analyze single prompt structure
ucx prompts sections   # Section inclusion matrix
ucx prompts tokens     # Token breakdown per persona
ucx prompts check      # Quick validation (all warnings)
```

**NOT implementing** (over-engineering):
- LLM-enhanced prompt generation
- A/B testing framework
- Few-shot example management
- Prompt versioning system

## Structure Detection

### Heuristic Patterns

When metadata is unavailable, `inspect` uses these patterns to detect prompt structure:

```python
STRUCTURE_PATTERNS = {
    "system_instructions": [
        r"^You are",
        r"^As an? (expert|senior|experienced)",
        r"^Your (role|task|job) is",
    ],
    "persona_definition": [
        r"^## \d+\. THE [A-Z]",
        r"^### (PERSONA|ROLE):",
        r"^## (Architect|Auditor|Tech Lead)",
    ],
    "prior_context": [
        r"^## PRIOR (FINDINGS|CONTEXT|REVIEWS)",
        r"^### Previous Persona",
        r"^The following personas have",
    ],
    "document_content": [
        r"^# (DOCUMENT|FILE|SECTION)",
        r"^## File: ",
        r"^# Section: BRD-",
    ],
    "format_instructions": [
        r"^## (OUTPUT|FORMAT|RESPONSE) (FORMAT|REQUIREMENTS|STRUCTURE)",
        r"^### Required Output",
        r"^You MUST (format|structure|output)",
    ],
}

def detect_structure(content: str) -> list[PromptSection]:
    """Detect prompt structure using heuristic patterns."""
    lines = content.split('\n')
    sections = []
    current_section = None

    for i, line in enumerate(lines):
        for section_type, patterns in STRUCTURE_PATTERNS.items():
            if any(re.match(p, line) for p in patterns):
                if current_section:
                    current_section.end_line = i - 1
                    sections.append(current_section)
                current_section = PromptSection(
                    name=section_type,
                    start_line=i + 1,  # 1-indexed
                    end_line=None,
                    char_count=0,
                    token_estimate=0,
                )
                break

    # Close final section
    if current_section:
        current_section.end_line = len(lines)
        sections.append(current_section)

    return sections
```

## Error Handling

### Exception Hierarchy

```python
class PromptInspectionError(Exception):
    """Base exception for prompt inspection toolset."""
    pass

class DocumentNotFoundError(PromptInspectionError):
    """Document path does not exist."""
    def __init__(self, path: Path):
        self.path = path
        super().__init__(f"Document not found: {path}")

class InvalidDocumentTypeError(PromptInspectionError):
    """Unknown document type."""
    def __init__(self, doc_type: str, valid_types: list[str]):
        self.doc_type = doc_type
        self.valid_types = valid_types
        super().__init__(
            f"Invalid document type: {doc_type}. "
            f"Valid types: {', '.join(valid_types)}"
        )

class PromptFileNotFoundError(PromptInspectionError):
    """Prompt file does not exist."""
    pass

class MetadataNotFoundError(PromptInspectionError):
    """Metadata file not found (non-fatal warning)."""
    pass

class PersonaNotFoundError(PromptInspectionError):
    """Unknown persona."""
    pass

class TokenBudgetExceededError(PromptInspectionError):
    """Token budget exceeded (for strict mode)."""
    def __init__(self, persona: str, tokens: int, budget: int):
        self.persona = persona
        self.tokens = tokens
        self.budget = budget
        super().__init__(
            f"{persona} exceeds budget: {tokens:,} > {budget:,} tokens"
        )
```

## Token Counting

### Methods

| Method | Accuracy | Speed | Dependency |
|--------|----------|-------|------------|
| `chars` | ±15% | Fast | None |
| `tiktoken` | ±2% | Slow | tiktoken |

### Implementation

```python
def estimate_tokens(text: str, method: str = "chars") -> int:
    """Estimate token count.

    Args:
        text: Input text
        method: "chars" (fast, ~4 chars/token) or "tiktoken" (accurate)

    Returns:
        Estimated token count
    """
    if method == "chars":
        return len(text) // 4
    elif method == "tiktoken":
        try:
            import tiktoken
            # cl100k_base is close to Claude's tokenizer
            enc = tiktoken.get_encoding("cl100k_base")
            return len(enc.encode(text))
        except ImportError:
            warnings.warn("tiktoken not installed, falling back to chars method")
            return len(text) // 4
    else:
        raise ValueError(f"Unknown method: {method}")
```

## Prior Context Simulation

When generating prompts for multiple personas, each persona (except the first) receives a summary of prior findings. For inspection purposes, this is simulated:

```python
def simulate_prior_responses(personas: list[str]) -> dict[str, str]:
    """Generate simulated prior responses for prompt generation."""
    responses = {}
    for i, persona in enumerate(personas):
        if i == 0:
            continue  # First persona has no prior context

        # Simulate what prior personas would have found
        prior_personas = personas[:i]
        responses[personas[i-1]] = f"""
## {personas[i-1].upper()} FINDINGS (Simulated)

This is a simulated summary of findings from the {personas[i-1]} persona.
In actual review, this would contain:
- Key findings (P0/P1/P2)
- Section-specific observations
- Cross-references to other sections

[Simulated for prompt inspection - {len(prior_personas)} prior personas]
"""
    return responses
```

### Problem Statement

4 personas had instruction ratios below the 5-10% target:

| Persona | Before | After | Improvement |
|---------|--------|-------|-------------|
