# UCX v1.15.0 Changelog

**Release Date**: 2026-03-14

## Summary

Extended the auto-fix suite from 13 to 17 fixable error codes, adding support for dependency tags, element section moves, automatic file splitting, and frontmatter creation.

## New Features

### BRD-W010: Auto-Detect @depends Tags

New `_fix_brd_w010` method automatically detects BRD references in document content and adds `@depends` metadata:

```bash
ucx validate brd docs/01_BRD/BRD-05 --fix
```

**Algorithm**:
1. Scan document for BRD references (BRD-01, BRD.02.01.01, etc.)
2. Extract unique BRD numbers, excluding self-references
3. Add to `custom_fields.depends` in frontmatter
4. Insert `<!-- @depends: BRD-01, BRD-02 -->` comment tag

**Example Output**:
```yaml
custom_fields:
  depends:
    - BRD-01
    - BRD-03
    - BRD-04
```

### GATE-W008: Move Elements to Correct Section

New `_fix_gate_w008` method moves elements to their correct section files based on type code:

| Type Code | Element Type | Target Section |
|-----------|--------------|----------------|
| 01 | Functional Requirement | Section 6 |
| 02 | Integration Point | Section 8 |
| 03 | Constraint | Section 9 |
| 04 | Assumption | Section 10 |
| 05 | Risk | Section 11 |
| 06 | Acceptance Criteria | Section 6 |
| 32 | Business Objective | Section 5 |
| 91-99 | QA Requirements | Section 7 |

**Behavior**:
- If target section file exists: Moves element block (### heading to next heading)
- If target section file missing: Adds `<!-- TODO: Move to Section X -->` comment

### GATE-E010: Auto-Split Large Files

New `_fix_gate_e010` method automatically splits files exceeding 20K tokens:

```bash
ucx validate brd docs/01_BRD/BRD-03_security --fix
```

**Algorithm**:
1. Parse `## N.` section headers
2. Group sections to stay under 15K tokens per file
3. Create new section files: `{doc_id}.{section_id}_{slug}.md`
4. Convert original file to index with section links

**Example Split**:
```
Before:
  BRD-03.6_functional_requirements.md (20,750 tokens)

After:
  BRD-03.6_functional_requirements.md (index)
  BRD-03.6.1_auth_requirements.md (8,200 tokens)
  BRD-03.6.2_data_requirements.md (7,100 tokens)
  BRD-03.6.3_compliance_requirements.md (5,450 tokens)
```

## Usage Examples

### Fix All Issues in a BRD

```bash
ucx validate brd docs/01_BRD/BRD-05_multi_agent_ai --fix
```

### Dry Run (Preview Changes)

```bash
ucx validate brd docs/01_BRD/BRD-05_multi_agent_ai --fix --dry-run
```

### Batch Fix All BRDs

```bash
for dir in docs/01_BRD/BRD-*/; do
  ucx validate brd "$dir" --fix
done
```
