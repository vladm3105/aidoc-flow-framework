# UCX v1.15.1 Changelog

**Release Date**: 2026-03-14

## Summary

Added BRD-E020 auto-fix capability for invalid element type codes. This fixer remaps invalid type codes (codes not in the valid 01-32, 91-99 range) to their most likely valid equivalents.

## New Features

### BRD-E020: Invalid Type Code Auto-Remapper

New `_fix_brd_e020` method automatically remaps invalid type codes to valid BRD element codes:

```bash
ucx validate brd docs/01_BRD/BRD-36 --fix
```

**Algorithm**:
1. Parse invalid type code from validation issue context
2. Look up code in `INVALID_CODE_REMAP` table (60+ mappings)
3. If not in table, infer from section context
4. Fall back to "01" (Functional Requirement) if no match
5. Replace all occurrences of the element ID in the file

**Remap Strategy**:

| Invalid Code Range | Target Valid Code | Rationale |
|--------------------|-------------------|-----------|
| 00, 11-19 | 01 | Functional Requirement (most common) |
| 20, 42, 52, 62, 72, 82 | 02 | Quality Attribute |
| 30, 31, 33, 43, 53, 63, 73, 83 | 03 | Constraint |
| 34, 40, 44, 54, 64, 74, 84 | 04 | Assumption |
| 25, 35, 45, 50, 55, 65, 75, 85 | 05 | Dependency |
| 26, 36, 46, 56, 60, 66, 76, 86 | 06 | Acceptance Criteria |
| 27, 37, 47, 57, 67, 70, 77, 87 | 07 | Risk |
| 28, 38, 48, 58, 68, 78, 80, 88 | 08 | Metric |
| 29, 39, 49, 59, 69, 79, 89 | 09 | User Story |
| 90 | 91 | Performance Requirement |

**Example Transformation**:
```
Before: BRD.36.45.01 (invalid code 45)
After:  BRD.36.05.01 (remapped to valid code 05 - Dependency)
```

## Recommendations

After running BRD-E020 auto-fix:
1. Re-run validation to confirm fix applied
2. Review GATE-W008 warnings (elements may need to move to correct sections)
3. Run `ucx validate brd <path> --fix` again to apply GATE-W008 fixes
